# Pre-0.1 mutation survivor review

This review records the deliberate classification of Infection's surviving mutants before Akashi's first release. It is
a point-in-time engineering record, not a promise that every future run will have zero survivors.

Review date: 2026-08-09. The baseline revision was `5f2bf51`; the final tree is the commit that first adds this record.
Naming the containing commit this way avoids an impossible self-referential commit hash while keeping it identifiable
through file history.

The baseline run generated 2,374 mutants: 2,153 were killed, 197 escaped, 13 errored, 9 had syntax errors, and 2 timed
out, for a 91% covered-code MSI. Focused behavioral tests and one removal of unused parser configuration reduced the
final escaped set to 92. The final run generated 2,398 mutants: 2,283 were killed, 92 escaped, 12 errored, 9 had syntax
errors, and 2 timed out, for a 96% covered-code MSI. Mutation code coverage remained 100%.

## Classifications

- **A — meaningful:** the mutation changes a documented guarantee. A focused regression test now covers the behavior.
- **B — equivalent:** the mutation is observably equivalent for supported inputs.
- **C — unreachable defense:** the mutation changes a guard for a state excluded by an upstream or local invariant.
- **D — tooling or environment:** the behavior is covered or deliberately defended, but Infection cannot distinguish it
  reliably in this environment.

Some rows use `A/D`: the behavior matters and has a focused test, but Infection still reports the mutant because its
include interceptor does not reach the relevant nested process or test path. Those cases were checked by applying the
mutation directly where noted.

## Timed-out mutants

Two mutants did not escape: `CommonMarkExampleExtractor.php:390` (`6db747f4191ecdba3eb1bbeb86399844`) and
`NamespaceIsolator.php:240` (`830165126e5240e811ac376dc720dab8`). Each turns a terminating loop condition into a
non-advancing loop. Existing tests exercise both paths, and Infection terminates the mutant at its configured 20-second
limit. They are recorded separately because timeout is the expected observable failure, not an accepted survivor.

## Outcome

All ordinary meaningful survivors found in the baseline were killed by focused tests. The remaining `A/D` entries have
behavioral regression tests and were confirmed outside Infection's interception boundary. The other escaped mutants are
equivalent, unreachable defensive branches, fixed-time/platform cases, or environmental failure guards; none was
suppressed, excluded, or used to lower the configured threshold.
