# Mutation survivor review

This record classifies every escaped mutant in Akashi's current post-0.2 mutation baseline. It is a point-in-time
engineering record, not a promise that every future run will have zero survivors.

Review date: 2026-08-29. Reviewed source baseline: `0948150`. The detailed editable-checkout run used Infection 0.32.6
on PHP 8.2.33:

```console
vendor/bin/infection --no-progress --min-msi=90 --min-covered-msi=90 --threads=max
```

That run generated 5,065 mutants: 4,902 were killed, 126 escaped, 18 errored, 12 had syntax errors, and 7 timed out.
Mutation code coverage was 100%, and covered-code MSI was 97%. The reproducible `nix build .#mutation -L` target also
passed with 126 escaped mutants and 97% covered-code MSI. Scheduling and environment changed two detected outcomes: Nix
reported 4,904 killed, 18 errored, 11 syntax errors, and 6 timeouts. The escaped count was stable.

The tables group repeated mutations with the same location and rationale. The **Count** column ensures that all 126
escaped mutants remain accounted for without recording source- and path-dependent Infection fingerprints.

## Classifications

- **A — meaningful:** the mutation changes a documented guarantee and needs focused behavioral coverage.
- **B — equivalent:** the mutation is observably equivalent for supported inputs.
- **C — unreachable defense:** the mutation changes a guard for a state excluded by an upstream or local invariant.
- **D — tooling or environment:** the behavior is covered or deliberately defended, but Infection cannot distinguish it
  reliably in this environment.

`A/D` means the behavior matters and focused coverage exists, but Infection's include interceptor does not carry the
in-memory mutation into the nested process or fixture that observes it. No ordinary class-A survivor remains.

## Outcome

All 126 current survivors are classified above. Existing focused tests protect the meaningful `A/D` behavior, and the
remaining survivors are equivalent transformations, unreachable defensive branches, or environment/tooling limits. No
suppressions or exclusions were added, thresholds remain 90% MSI and 90% covered MSI, and no test was added merely to
assert private mechanics or a mutation-tool artifact.
