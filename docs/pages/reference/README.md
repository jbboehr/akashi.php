# Reference

The reference chapters describe Akashi's implemented user-facing workflows:

- [Extraction CLI](cli.md) selects one explicitly marked example without executing it.
- [Runtime and PHPUnit](runtime.md) discovers named data sets and executes examples through the selected backend.
- [PHPStan Verification](phpstan.md) analyzes a relevant subcorpus from a consumer `RuleTestCase`.

See [Authoring Markdown Examples](../authoring-markdown.md) for corpus discovery, fences, markers, and directives, and
[Compatibility and Limitations](../compatibility.md) for the current support boundary.
